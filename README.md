# VOXEL STUDIO 3D

3Dブロックを積み上げて作品を作る、ブラウザで動くクリエイターツールです。

https://tt-sensei.github.io/voxel-studio-3d/

## できること

- 20×20のベースプレートにブロックを配置（6種の形：1x1ボクセル／1x1ポッチ／2x1／2x2／スロープ／円柱）
- 18色＋自由カラー、4種の質感（標準・マット・クリア・ネオン）
- ツール：配置／削除／塗り替え／スポイト、ブロック回転（Rキー）、X・Zの対称ミラー
- 元に戻す／やり直す（Ctrl+Z / Ctrl+Y）、全消去
- サンプル作品4点（家・ロボット・庭園・ロケット）を読み込んで改造できる
- 作品の自動保存（端末のブラウザに保存され、次回は続きから始まります）
- JSONファイルでの保存・読み込み、PNG撮影
- 背景テーマ2種（ライト／スカイ）、効果音のON/OFF
- ナビキャラのガイド：開くたびに6人のうち1人が案内役になり、場面に合わせて表情とひとことが変わります（画像は navi-character- サイトから読み込み）

## 操作

- 左クリック／タップ：ブロック配置
- Shift+クリック／右クリック：素早く削除
- 右ドラッグ：視点回転、中ドラッグ：平行移動、ホイール／ピンチ：ズーム
- カメラ視点ボタン（リセット・斜め・正面・上面）でも見方を変えられます

## 技術メモ

- three.js r172 を `lib/` に同梱し、外部CDN・外部フォントを使わずオフラインでも動きます
- UIのスタイルは `css/style.css` に自前で定義しています
- 作品データは localStorage（キー `voxelStudio3d.save.v1`）に自動保存されます
